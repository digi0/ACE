#
# This file is belt to the braces of the <meta name="robots" content="noindex">
# in index.html. Keep both: robots.txt stops the crawl, the meta tag is what
# actually removes a URL that some other site has already linked to, and a
# disallowed page can never be re-crawled to discover its own noindex.
